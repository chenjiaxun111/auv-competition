# Jetson 真实 ZED 影子模式验证报告

日期：2026-09-14  
验证等级：L3（真实相机、机器人执行器断开）

## 运行方式

Jetson 入口：

```bash
bash /home/auv/run_zed_shadow.sh
```

默认使用 `ROS_DOMAIN_ID=96`，临时映射 `person=ball`、`tv=gate`。退出使用 `Ctrl+C`，脚本同时停止控制器与它启动的 ZED 进程。

## 安全边界

- 启动脚本检测到 `thruster_bridge_node` 时拒绝运行。
- 影子节点仅向 `/auv/shadow/*` 发布运动意图。
- 最终运行审计中 `/auv/control_command` 和 `/auv/motion_enable` 均不存在。
- NanoPi auvmaster 和 Jetson 推进器桥均未运行。
- 域42存在一个来源未知的真实控制话题发布者，故本测试改用并固定为域96。

## 实测结果

- `/zed/objects3d`：1个发布者 `/zed_yolo_3d`，1个订阅者 `/competition_shadow_controller`。
- 控制状态：`DIVE → SEARCH_BALL → ALIGN_BALL`。
- 临时目标：COCO `person`。
- 决策流示例：目标约 `X=+0.169 m, Y=-0.081 m, Z=0.225 m`，置信度约 `0.766`，感知年龄约 `7.3 ms`，请求偏航约 `+18.1`，执行器未接收该意图。
- 运行期间常见感知年龄约 `1～35 ms`，解析错误为0。
- `/auv/shadow/decision` 包含模式、状态、四轴请求值、目标深度、目标XYZ、置信度、消息年龄、接收/拒绝数量及决策原因。

## 尚未证明

- COCO 类别不是比赛球/门模型，不能评价比赛识别率。
- 本次画面没有稳定 `tv` 目标，未用真实视觉触发过门分支。
- 虚拟初始深度仅用于推进影子状态机；不代表深度传感器或定深闭环有效。
- 没有向 NanoPi 发送控制，因此没有验证 PWM、电机、推进器方向和机器人运动。
