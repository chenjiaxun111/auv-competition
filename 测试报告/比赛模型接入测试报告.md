# 比赛模型接入测试报告

测试日期：2026-09-16

## 结论

新模型已成功部署到 Jetson，能由 ZED SDK 构建 TensorRT 引擎并以约 28.6 FPS 输出类别、置信度和相机坐标系三维坐标。ROS 2 影子控制器也能正确选择 `red_ball` / `blue_ball` / `gate` 类别。

但当前模型会把左侧黑色显示器持续误检为 `blue_ball`，且置信度高达约 0.88。这会直接触发球对准控制，因此模型尚不具备下发真实运动指令的条件。本轮只达到 **L4（硬件上电、执行器路径隔离）**，没有运行会改变 NanoPi PWM 的全链测试。

## ROS 2 影子链结果

选择蓝球时，状态机实测转移：

```text
DIVE -> SEARCH_BALL -> ALIGN_BALL
```

误检目标进入控制器后，产生过 `yaw=-20.0` 和 `yaw=+20.0` 的对准意图，目标坐标还出现左右跳变。这证明感知消息和类别映射已成功进入视觉伺服，同时也证明当前模型不能与真实执行器连接。

测试过程中未启动 `rov_thruster_bridge`，只发布 `/auv/shadow/*`，未向 NanoPi 发送运动命令。测试后无检测器、控制器或桥接残留进程。
